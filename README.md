# 🏠 California House Price Prediction

A Machine Learning project built with Python to predict housing prices in California using baseline and ensemble models.

## 📊 Project Overview
This project explores the California Housing dataset, performs Exploratory Data Analysis (EDA), and compares two Machine Learning models to accurately estimate property values.

## 🚀 Model Performance
| Model | MSE | R² Score |
| :--- | :--- | :--- |
| **Linear Regression** (Baseline) | 0.5559 | 57.58% |
| **Random Forest Regressor** | 0.2560 | **80.46%** |

## 🛠️ Features
- Exploratory Data Analysis (EDA)
- Feature engineering and train-test splitting
- Model evaluation & metric analysis
- Interactive Command-Line Interface (CLI) for custom price estimation
